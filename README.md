# Global Seismic Trends: Data-Driven Earthquake Insights

## Project Overview

This project analyzes global earthquake data to identify important patterns and trends in earthquake magnitude, depth, location, and occurrence over time.

The project uses Python, Pandas, SQL, and data visualization techniques to explore earthquake data and generate meaningful insights.

## Objectives

* Analyze global earthquake data
* Understand earthquake magnitude and depth
* Identify the strongest earthquakes
* Analyze earthquake occurrences over time
* Study geographical patterns of earthquakes
* Visualize important earthquake trends
* Generate data-driven insights

## Technologies Used

* Python
* Pandas
* NumPy
* MySQL / SQL
* Matplotlib
* Seaborn
* Streamlit
* Jupyter Notebook

## Project Workflow

1. Collect the earthquake dataset
2. Load and inspect the data
3. Clean and preprocess the data
4. Handle missing and duplicate values
5. Perform exploratory data analysis
6. Analyze earthquake magnitude and depth
7. Analyze geographical and time-based patterns
8. Create visualizations
9. Generate meaningful insights
10. Build the Streamlit application

## Analysis Performed

The project includes analysis of:

* Earthquake magnitude
* Earthquake depth
* Latitude and longitude
* Earthquake frequency
* Strongest earthquakes
* Deepest earthquakes
* Earthquake occurrence by year and month
* Geographical distribution of earthquakes

## Key Insights

The analysis helps identify patterns in earthquake magnitude, depth, location, and occurrence over time.

The visualizations provide a clear understanding of global seismic activity and help transform earthquake data into meaningful insights.

## Project Files

* `Earthquake Final` – Main Jupyter Notebook containing the project analysis.
* Supporting dataset and cleaned data files are used for analysis.

## Streamlit Application

A Streamlit application was developed to provide an interactive way to explore the earthquake analysis and visualize important seismic trends.

## Conclusion

This project demonstrates how data analysis, SQL, Python, and visualization techniques can be used to analyze global earthquake data and generate useful data-driven insights.
